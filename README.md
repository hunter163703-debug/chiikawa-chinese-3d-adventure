# 吉伊卡哇 3D 冒險拯救大作戰：探索萌島與生字語詞書寫 🌸🐾🐰

專為國小第一課與第二課生字語詞打造的 **吉伊卡哇 (Chiikawa) 風格 3D 萌島物品探索與書寫練習單一檔案網頁遊戲 (Single-File HTML5 Web App)**。

無需後端伺服器，所有程式碼 (HTML, CSS, JS)、3D 物品與角色 (Three.js)、音效合成 (Web Audio API) 與語音朗讀 (SpeechSynthesis API) 完全整合於 `index.html` 單一檔案，可直接儲存並在 iPad、平板、智慧型手機或電腦瀏覽器中順暢遊玩。

---

## 🎮 遊戲故事背景與玩法機制

調皮的怪盜影子把好朋友 **小八貓 (Hachiware)** 關在銀色籠子裡，把 **烏薩奇 (Usagi)** 關在金色籠子裡！
吉伊卡哇要在萌島上自由漫步探險，尋找散落各處的神祕物品進行闖關挑戰，並**隨機獲得金色或銀色的神奇鑰匙**：

1. **探索 10 種不同的萌島物品**：
   - 🎁 **神祕糖果寶箱**：解開寶箱上的生字鎖印。
   - ⭐ **許願幸運星**：寫出國字喚醒星辰力量。
   - 🍄 **幻彩魔力菇**：破解蘑菇散發的生字密碼。
   - 💎 **奇蹟能量水晶**：與水晶共鳴解開字詞挑戰。
   - 🧁 **巨型草莓蛋糕**：答對字詞品嚐甜蜜滋味。
   - 🌳 **守護精靈樹洞**：回答老樹爺爺的智慧謎語。
   - ⛲ **夢幻願望之泉**：向許願池投入正確國字。
   - 🎡 **彩色旋轉風車**：隨微風解讀旋轉中的字詞。
   - 💌 **浪花漂流瓶**：閱讀漂流信籤中的謎題。
   - 🌸 **巨型向陽花**：獲取花仙子的生字祝福。
2. **隨機獲得金色或銀色鑰匙**：每次成功答對並完成物品闖關時，系統將動態隨機發放 1 把銀色鑰匙或金色鑰匙！
3. **全員大拯救**：
   - 累積 5 把銀色鑰匙 ➔ 解鎖銀色籠子拯救小八貓 🐾！
   - 累積 5 把金色鑰匙 ➔ 解鎖金色籠子拯救烏薩奇 🐰！
   - 10 把鑰匙全數收齊 ➔ 觸發全螢幕煙火彩帶慶祝與頒發榮譽證書！

## 🌟 核心功能與操作指南

### 1. 課次切換系統 (即時更新題庫)
- 頂部選單可自由切換：
  - **第一課：你好，新朋友**
  - **第二課：我們的約定**
  - **🌟 綜合大挑戰**（第一課 + 第二課隨機抽選 10 題）

### 2. 雙模式題目挑戰 (Tabs)
- **✍️ 純淨書寫練字模式**：
  - 標準 **米字格** 畫布，**無任何筆畫提示洩題**，由學生自主書寫。
  - 工具列：🌸 **粉紅筆**、🌊 **藍筆**、🍫 **棕黑筆**、🧹 **橡皮擦** 與 🗑️ **清除重寫**。
  - 完成手寫後點擊「🌟 我寫好了！送出驗證」。
- **💡 提示與測驗模式**：
  - 提供 **部首提示** 與 **教育部詞義例句**。
  - **四選一選項卡**：點選即時判斷正誤。
  - **打字輸入模式**：支援鍵盤直接打字輸入。

### 3. 進階語音與正向回饋機制 (Web Audio + TTS)
- **左上角全域開關**：`🔔 聲音開啟 / 🔕 已靜音`。
- **答對正向回饋節奏**：
  1. 即時 (0s)：Web Audio 清脆雙音階叮咚聲（C5 -> G5）。
  2. 延遲 0.6s：TTS 朗讀「答對了！」。
  3. 延遲 0.8s：隨機語音鼓勵（「你真棒！」、「太強了！」、「一百分！」、「好厲害！」等）。
  4. 延遲 2.0s：隨機獲得金色或銀色鑰匙，更新 HUD 進度並推進探險！

### 4. 3D 世界操作方式
- **iPad / 平板 / 手機**：
  - 左下角內建 **觸控虛擬搖桿 (Virtual Joystick)**。
  - 右下角「🚀 帶我去下一個冒險物品」快捷導航。
  - 點擊地面可自動尋路移動。
- **電腦鍵盤 / 滑鼠**：
  - `W / A / S / D` 或 方向鍵移動吉伊卡哇。
  - 滑鼠點擊地面移動。
  - 靠近物品自動浮現「✨ 探索【物品名稱】」對話泡泡。
