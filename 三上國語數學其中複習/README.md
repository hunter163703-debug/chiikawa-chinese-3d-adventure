# 國小三年級寶可夢訓練道館（三上國語・數學期中複習 RPG）

結合經典 2D 俯視角寶可夢城鎮探索與國小三年級上學期國語、數學期中複習的互動式教學遊戲網頁。

## 🎮 遊戲流程與特色

1. **初始寶可夢三選一**：
   - 遊戲開始時可從 **皮卡丘**、**噴火龍**、**妙蛙種子** 中選擇一隻作為初始夥伴（Lv.1 未受訓狀態）。
2. **主城「柳溪」三大建築**：
   - **📕 國語文道館（南一版第 1～6 課｜提升寶可夢攻擊力 ATK）**
     - **(a) 初階：生字聽寫活動**：純語音出題 + iPad/滑鼠空白田字格手寫辨識，移除所有畫面洩題提示，下方僅提供 **「1. 部首提示」** 與 **「2. 第一筆畫提示」**。
     - **(b) 中階：照樣造句／詞語造句活動**
     - **(c) 高階：閱讀測驗活動**
   - **📘 數學道館（康軒版第 1～4 單元｜提升寶可夢防禦力 DEF）**
     - **(a) 初階：乘法與基本運算**
     - **(b) 中階：一萬以內的四位數加減（直式呈現與直式手寫計算）**
     - **(c) 高階：第 1～4 單元素養題與應用題**
   - **🏪 寶可夢商店 & 醫療中心**：
     - 可使用地圖寶箱獲得的金幣（`₽`）購買精靈球、超級球、高級球、傷藥、攻擊/防禦強化劑與經驗糖果，並可免費恢復全隊 HP。
3. **五大地圖與遭遇階梯**：
   - **若葉鎮／29 號道路（Lv.3～6）**：一般寶可夢與少量初階進化型，熟悉移動、收服和道館訓練。
   - **吉花市海灣／30 號水路（Lv.7～12）**：一般與第一階段進化型，草叢、水域分開遭遇；完成兩館基礎訓練後解鎖。
   - **檜皮鎮／櫟樹林（Lv.12～18）**：進化型與少量稀有型；需兩館初階徽章並完成指定訓練。
   - **淺蔥市海岸／光輝燈塔（Lv.18～25）**：中高階進化型與稀有型，不會遭遇古代或傳說型；需先擊敗櫟樹林守護者。
   - **韋斯頓露台／古代遺跡（Lv.25～32）**：高階、古代型與特殊傳說首領；需完成兩館最高階課程、取得兩枚大師徽章並擊敗海岸守護者。首領挑戰等級為 Lv.35～40。
   - 各地圖包含普通區、深層區與石碑首領特殊區。稀有／古代遭遇有每區次數上限；收服難度隨稀有度增加，古代與傳說夥伴的 EXP 成長較慢。
